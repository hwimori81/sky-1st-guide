# 《영웅전설 하늘의 궤적 the 1st》 100% 퍼펙트 인터랙티브 공략집

Nintendo Switch 2 / 리메이크 버전에 완벽 대응하는 **《영웅전설 하늘의 궤적 the 1st》** 올인원 인터랙티브 웹 공략집입니다.

## 주요 기능
- **전 챕터 스텝업 차트 (서장 ~ 종장):** 만점 **395 BP** 달성 루트, 추가 BP 선택지 정답, 히든 퀘스트, 보물상자 전수 체크리스트
- **시한부 수집품 완벽 추적:** 《카넬리아》 전 11권, 《리벨 통신》 전 9호, 대표 요리 28종 레시피
- **플레이어블 8인 캐릭터 & 파티 빌드:** 캐릭터별 티어, 오브먼트 라인 구조, 추천 쿼츠 세팅 및 최강 파티 3선
- **인터랙티브 아츠·쿼츠 계산기:** 원하는 아츠 복수 선택 시 단일 라인 필요 속성치 합산 및 최소 슬롯 쿼츠 조합 추천
- **보스 & 수배 마수 파훼표:** 장별 주요 보스 및 최종 보스 약점·상태이상·공략법
- **준유격사 랭크·샤이닝 폼·최강 장비·시스템:** 실시간 BP 연동 등급표, 장별 샤이닝 폼 확정 원킬 파밍법, 리메이크 신규 전투 시스템 및 2nd 세이브 연동 가이드
- **편의 기능:** 브라우저 자동 저장(`localStorage`), `⏳ 미완료만 보기` 필터, `💾 백업/복원 (PC↔모바일 동기화 코드 & JSON)`, 다크/라이트 테마 지원
